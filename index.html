Arm MCP Server: open-source fix

October 2026 · merged into arm/mcp

I ran Arm's official MCP server locally and called its tools directly with MCP Inspector, with no AI in the loop. The mca tool's triple option always failed: the code passed --triple to llvm-mca, but the real flag is --mtriple.

I traced it to one line, submitted the fix with a regression test that fails without the fix and passes with it, ran Arm's test suite locally, and Arm merged it into main. I also compared -O0 and -O2 AArch64 code on a Neoverse V2 model: about 12× faster per element at -O2.
